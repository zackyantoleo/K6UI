Load Mode

VUs simulate concurrent users running your request flow.

Duration is how long each fixed period or ramp stage runs.

What these terms mean

VUs simulate concurrent users. One VU repeatedly runs the complete request flow.

Duration is how long the load remains fixed or ramps toward its target.

Duration examples

30s30 seconds
5m5 minutes
1h1 hour
1h30m1 hour 30 minutes

Staged mode: each stage defines a transition from the current VU count to the target VU count over the given time range.

The test is considered failed (exit code ≠ 0) if these performance targets are not met — useful for CI/CD pipelines.

Performance Targets

p95 means 95% of requests must finish below this response time.
Error rate is the percentage of HTTP requests allowed to fail.

What are Thresholds?

Thresholds are the pass criteria for the test. If they are not met, k6 exits with exit code 99.

Example: if you set p95 = 500ms and 5% of requests exceed it, the test is marked FAILED.

    Variables
    
              
    
              
            
    

            
    
              
    How it works
    
              
    Reference a variable as {{name}} in a URL, header, or body — e.g. {{base_url}}/users.
    
              
    Names must start with a letter or underscore and contain only letters, digits, and underscores.
    
              
    If a request extracts a variable with the same name, the extracted value overrides the global one for the requests that follow.

            e.g. Content-Type, Accept, or an Authorization token.
          
    
          
    
            
    
              
    Headers
    
              
    
              
            
    

            
    
              
    How it works
    
              
    These headers are sent with every request in the scenario, including Before and After sub-requests.
    
              
    Values can use {{name}} variables — e.g. Bearer {{token}} with a global or extracted variable.
    
              
    If a request defines a header with the same name, the request's value overrides the global one (names are case-insensitive).
